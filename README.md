A program that writes one short poem about agency — two agents agreeing on one plan — to /output/entry.txt. Deterministic: the same 230 characters on every run.

## Run it

```sh
python3 main.py
```

The poem is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
